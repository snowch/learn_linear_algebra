Learn Linear Algebra hands-on with SageMath

This project is a JupyterBook.

## Build the book

To build the book, run the following command:

```bash
jupyter-book build .
```

## Interactive course — no installation required

[Open Learn Linear Algebra in your browser](https://snowch.github.io/learn_linear_algebra/interactive/).

The interactive version covers 21 lessons, from vectors to PCA, with visual experiments, guided practice, and optional Python running locally through WebAssembly. No SageMath or notebook server is required. The original book and notebooks remain available at their existing links.

Source, tests, and development instructions: [interactive/README.md](interactive/README.md).
